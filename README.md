# ⚽ Football Quiz Bot

A simple, lightweight Telegram trivia bot that quizzes users on football (soccer) knowledge. Built with `python-telegram-bot` and deployed on Railway via GitHub.

> **No gambling. No betting. No prizes. Just trivia.** ✅

## ✨ Features

- 🎯 Multiple-choice football trivia questions
- 🖱️ Inline keyboard buttons (no typing answers)
- 🏆 Live score tracking per session
- 🔁 Auto-reset after quiz completion
- ⚡ Zero database required (in-memory storage)
- 🚀 One-click deployment on Railway

This bot is designed to comply with **Telegram Bot Policy** and **Telegram Ads Policy**:
